# Double-column fixtures

`elsevier_two_column.pdf` is generated by `tests/fixtures.py`. It simulates an Elsevier-like two-column page, with a full-width abstract, page-two reference, text layer, DOI/URL and internal navigation link, and bookmarks. It is synthetic layout content, not a real Elsevier article.

The real regression source is Han (`external_samples.han` → `work/han2025/source.pdf`, 9 pages). Real-source coverage and synthetic coverage are distinct in `tests/corpus.json`.
