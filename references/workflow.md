# 版式、来源与核查

## 来源优先级

原 PDF 是文字、图表、公式、页码与编号的基准。提取工具只帮助定位；用独立来源清单核对覆盖，遇到缺失、读序或分类疑点时对照相应原页补全。补充材料只有实际取得并核对后才能随包声称已提供；正文中补充图引用保留，缺附件时不伪造跳转。

英文来源段落与中文逐段映射，标记跨页段落并保持读序。正文、图注、材料方法、编号及未编号方程、变量定义、数据可用性与声明均按用户全文范围处理。参考文献单独提取，必须核对连续编号、跨栏延续及最后一条；不把页眉或致谢混进书目。

## 并发执行

默认串行。仅在用户明确要求并发时启用；篇幅长、可分章节不构成启用理由。`config.yaml` 的 `concurrency: 1` 控制适配器，不自动限制宿主子代理，宿主也须遵守串行默认值。

用户要求并发后，按不重叠的完整段落组分配 ID，跨页段落留在同组。只传分配的原文、必要邻近上下文、相关术语与规则，不复制整段会话、整篇论文或全部技能文档。子任务只返回 `{id: 中文}` 和疑点，主任务合并后跑机械审计、复核疑点与章节衔接，不再重复翻译所有结果。V4 用 `translate --translations` 提交；旧流程才使用 `prepare_reader.py merge`。

不为预检、渲染或机械校验另开模型子任务；本地脚本计算与模型并发要区分。并发失败只补失败 ID。保留相同质量门禁，实测耗时和可取得的 Token，不预设加速或节省比例。

## 本流程的可复用实现

以下用于理解既有脚本；只在定位相关故障或明确维护任务时读取，不要求每篇论文重写实现。返工边界遵守 [SKILL.md](../SKILL.md#检查与返工边界)。

使用 PyMuPDF：从原 PDF 复制页面，针对文字区域加 redaction，再用 `apply_redactions(images=0, graphics=0, text=0)` 去文字。`fill=None` 可保留原线条；实际是否伤及图中矢量文字由保护区域的像素比较验证。选区不要穿过图片、公式或另一栏。扫描版不能靠删除文字去掉英文，需单独制作经视觉核查的遮盖区域。

`insert_htmlbox` 配合本地 CJK 字体，正文可选中、搜索；保留数学上下标。先调整区域与段距，尽量避免大幅缩小字体。每个区域单独记录字体大小、缩放和剩余高度。动态串排的内容核查区域应只到该段实际底部，否则会把下一段一起纳入，产生误报。

HTML 渲染的 URI 注释可先使用明确命名的临时链接，再转换为 PDF 标准 GoTo 链接。同一链接可能生成多个字符级点击区域；不要仅靠数量判定引用覆盖。最终检查临时域名没有残留，所有目标有效且与引用相符。

多次 HTML 排版可能重复嵌入整套字体，造成内存和文件膨胀。先 subset 字体、压缩保存到工作目录，再重新打开解析注释；避免把巨大的未压缩文档直接 `tobytes()`。

## 局部冲突的修复顺序

按 [主技能已确认的阅读版标准](../SKILL.md#已确认的默认阅读版标准2026-10-20) 处理：原位法可在保护区之外适度扩展、合并同栏段落区域；重排法允许自然续栏和换页。普通留白、位置偏移或轻微间距差异已获接受，不单独要求用户确认，也不作为反复重建的理由；只有内容、清楚阅读或引用功能受损才返修。

先检查来源块是否混合正文、独立公式或跨栏内容，重新划分正文区域并保持完整段落映射；独立公式与图形保留原貌，行内化学式和变量正确排版。再调整段距、换行与字号。删除文字后残留的行内矢量笔画，只在经过核对且不与保护区相交的正文区域用 overlays 覆盖。不能缩小保护区来掩盖损坏，也不能将一次失败解释为整篇必须附译页。

PDF 删除文字可能使原矢量颜色状态继承发生变化；构建脚本通过 pdf_colors.py 捕获并修复受影响绘制指令的显式颜色，仍需以保护区像素检验确认。字体预检失败时配置覆盖缺字的 fallback 字体，并复查科学符号和版面。已确认的成品样例优先于通用字号建议。

## 引用标记

优先从 PDF 上标位置和上下文判断，建立显式映射。独立的 Unicode 上标也可能是化学价态、单位或同位素：例如 Fe⁴⁺、cm⁻²、¹⁸O 均不是文献。不要全局将所有上标数字变成文献链接。范围如 9–11 可为端点分别创建链接，或明确标注跳到范围首条；不冒称能逐项点击。

## 验证

默认在翻译生成时逐段保留语义，完成后执行全量机械审计，模型重点核对报警、关键条件、否定、专业词义与机制推断。用户选择“优秀”或“完美”（旧称“精校”）时才进行全文第二遍对照；默认“可以接受”档不增加全文复审。数值、单位、图号及文献标号异常按 ID 复核，原文疑点保留并记录，不能代作者修正。

保护区域：以同一 DPI 比较相同坐标，按主技能的现有容差区分警告与实际损坏；不要求逐像素复刻。若用户明确要求翻译图内标签，应单独声明该区域已改变，并用逐标签映射与视觉复核代替像素一致要求。

构建脚本生成预览；结果未变时复用已有检查。默认“可以接受”档通过功能检查后可直接交付，警告不要求重建；需要时快速查看 `.overview.pdf`，只放大真实异常，不把逐页巡视或手动点击当作默认交付前置条件。优秀/完美档才增加相应视觉精修。结构校验与实际查看/点击分别如实记录，详见 [三档验收](translation-quality.md#三档质量与验收)。
