# 学术翻译、术语与成本

质量目标是忠实且自然的学术中文，不是摘要、自由改写或“期刊官方译文”。nature-reader 是工作规则，不是另一个翻译模型；名称不代表 Nature 官方认证。

## 先建立术语表

每项记录 english、chinese、abbreviation、definition、source、allowed_variants、confidence。标准译法应来自领域语境、作者定义或可靠术语资料；存在分歧时首次保留英文。缩写的同形不同义分开记录，例如 AEM 机理与 anion-exchange membrane，不能机械全局替换。

同一概念全篇用同一译名，不为文采替换近义词。材料名、基因、模型、分子式和作者自定义名称保留；原文拼写或全称有疑点时记录，而不悄悄改英文来源。没有可靠依据不自创“标准译法”。

## 翻译和校读

按完整段落或小节组成批次，保留必要上下文，稳定 block ID。同一会话内复用稳定术语和规则，每批只读取相关术语及必要上下文；不重新加载整套参考文档。逐段保留限定词、条件、否定、因果、比较基准与证据强度；suggests 不能升级成 proves。方法参数、样本量、统计口径、引用、单位和反应符号逐项核对。

### 三档质量与验收

默认使用“可以接受”档；用户指定“优秀”“完美”时才增加相应校读和精修。旧称“快速档”对应“可以接受”，“精校档”对应“优秀”；不自动升级。档位是宿主工作约定，当前没有同名 CLI 开关。

三档共同要求：翻译准确、表达清楚、术语一致、内容完整。不得漏译、截断译文、改错关键数字与单位、颠倒否定或因果、强化证据结论，或损坏图像、公式与引用跳转。降档只调整以下三项，不授权翻译腔、含糊表达或语义错误。

| 项目 | 可以接受（默认） | 优秀 | 完美 |
|---|---|---|---|
| 校读深度 | 生成时保全逐段语义；全量机械审计后重点对照报警、方法关键条件、专业术语、否定与机制推断，不默认全文第二遍对照 | 增加全文逐段对照，先核语义、术语和数值，再调整中文语序 | 在优秀基础上，专项复核复杂论证、跨段关系与高风险表述；不默认再重译全文 |
| 排版精细度 | 阅读顺畅即可，允许局部留白、普通换行和微型块缩放；不强制逐页巡视，需要时快速看拼图，只放大真实异常 | 逐页放大检查，调整明显不协调的字号、间距、图注与跨页衔接 | 逐页精修并放大检查重点细节，尽量贴近原版；仍遵守字号和保护区约束 |
| 轻微像素差异 | 现有容差内的差异记录为警告即可交付，不强制局部对照、不自动返工 | 有明确方案时最多修正一次，残余轻微差异记录交付 | 在优秀基础上细查残余差异，但不增加返工轮次，也不追求像素绝对一致 |

保留已有结构、覆盖、字体、像素与链接检查。默认采用主技能的自动拟合和宽松分级，警告正常交付；只在存在内容缺失或实际难读依据时针对性核查。不得删除保护登记或伪装内容损坏。

“完美”是精修档位名称，不承诺绝对零错。各档均按 SKILL.md 的返工边界处理，不因档位更高无限返工，不要求第二次构建必然成功。机械检查不能证明专业含义正确；交付报告写明实际档位、校读范围和未决疑点，不能仅凭零报警声称准确。升级档位复用合格译文与检查结果，只补相应校读和排版工作。

三档均可拆长句，不拆断证据链；不加“显著、首次、突破”等原文没有的强化词。默认不分派子代理；用户明确要求并发时按 [workflow.md](workflow.md#并发执行) 处理。不自行更换模型，不能把并发当作节省 Token 的措施。

已有流水线包含的检查不重复运行；缺少对应审计或排查异常时，`translation_audit.py --map source_map.json --output audit.json` 可检查缺译、编号、数值与术语候选。输入 blocks 用 source_text/translation 或 text_en/text_zh；expected_block_ids 来自独立完整来源清单，不能只把现有译文 ID 复制过来。source_citations/translation_citations 用显式文献编号数组。数字差异是待核查信号，可能因格式归一化误报，不自动更改文本。

## Token 与速度

局部错误只重译对应 ID，按 [返工边界](../SKILL.md#检查与返工边界) 有限修正；不另开全篇复审任务。字体缺字先修字体，排版问题先修布局，不为通过检查删减原义。

分别记录提取、翻译、校读、排版、验证的实际耗时。MinerU 提取不是翻译模型的计费 Token；其 API 凭据和额度也要另行说明。

以源段落哈希、术语表版本、翻译规则版本、模型及语言组成翻译缓存键。只重译变动或未通过校读的段落；修改字体和图号链接时复用译文，不重新发送全文。公式原貌与图片由本地 PDF 复用，不重复要求模型生成。默认只读当前待译包中的 `blocks`、`neighbor_context`、`terms` 和必要 `instructions`；`_source`、`_frozen`、`_context` 等完整校验数据留在本地，不重复打印进会话。不要在源码、日志和合并文件里再次输出相同全文；读取时过滤字段，不删改磁盘上的校验数据。

不能宣传固定节省百分比、准确率或“每篇几分钟”。若模型接口返回 usage，记录 input_tokens、output_tokens、cached_tokens 和模型；未提供则写 null/未测量。通过宿主 AI 执行翻译的本技能不另内置模型账号；更好的模型或更完整的校读通常有额外成本，不能同时保证最高准确率、最低 Token 和最快速度。

对外报告应包括来源覆盖、关键术语检查、数值与公式检查、实际耗时、可测的 Token、未决疑点。不要把检查通过率当翻译准确率。

数值检查忽略 [[ref:N|标签]] 等显式导航标记，引用编号另用 source_citations/translation_citations 核对。原文普通文本中的文献号与实验数字仍需人工区分，不猜测删除科学指数。
