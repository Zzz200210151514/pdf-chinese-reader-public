# 阅读字体与排版指南（HTML 离线阅读版）

以学术期刊的原版阅读体感为基准。优秀的排版应降低认知负荷，让读者专注于论文内容本身，而不是粗糙的机械排版或眼花缭乱的杂乱信息。

> PDF 原位重建的字体选型、平台字体表与溢出处理顺序见 [pdf-fonts.md](pdf-fonts.md)，本文不重复。

## 1. 为什么原版 HTML 容易"没有阅读欲望"
- **字体错配**：默认使用 Windows 系统微软雅黑（UI 无衬线体），笔画刚硬机械、西文字母宽大失衡，通篇给人"后台管理页面"或"行政网站"的冰冷感，完全丧失学术期刊的权威质感。
- **行宽失控**：直接放满 800px+ 容器，每行 50+ 个汉字，眼睛扫描一行后极易找错下一行，造成严重阅读疲劳。
- **段落割裂**：段后间距过大且每段下方堆砌固定的调试级信息（"原 PDF 第 x 页 · 对应英文"），割裂正常的阅读心流。
- **引用像按钮**：文献引用被渲染成"文献 12"大字粗按钮，而非原版的上标数字。

## 2. 推荐字体搭配方案

| 风格定位 | 正文字体 | 标题 / 图注字体 | 西文字体 | 适用场景与体感 |
|---|---|---|---|---|
| **学术原版（强烈推荐）** | **思源宋体 / Noto Serif SC**（推荐 450–500 字重） | **思源黑体 / Noto Sans SC** Bold | **Source Serif 4** / Cambria / Georgia | 最贴近 Nature / Science / Cell 原刊体感；典雅庄重、西文与化学式协调，长时间阅读舒适 |
| **温润护眼（深度精读）** | **霞鹜文楷 (LXGW WenKai)** | **思源黑体** Medium | **Source Serif 4** / Georgia | 类似精装实体书籍，笔画有手写温度，适合偏好楷体阅读的用户 |
| **现代清爽（科技无衬线）** | **思源黑体 / Noto Sans SC** Regular | **思源黑体** Bold | Segoe UI / Arial | 现代技术报告风格，干练利落，适合屏幕速读 |

> **提示：跨设备字体子集化内嵌 (`--embed-font`)**
> 导出 HTML 时可用 `reader_export.py --embed-font serif=...` 子集化并内嵌允许分发的字体。需要 fontTools，可选 brotli；字体覆盖、文件增量和跨平台显示需按实际内容验证，不能保证每个平台完全相同。

## 3. HTML 排版起点
- **默认阅读行宽**：`max-width: 36rem`（在 18px 字号下，每行容纳约 34–38 个汉字），左右留白通透，视线跳行自然。
- **行高与节奏**：正文行高 `line-height: 1.82`，段落首行缩进 `2em`，段间距 `0.6em`，保持书卷式连贯流动。
- **文献与图表引用**：
  - 文献引用采用显式引用标记生成的上标 `<sup>`（如 `[[ref:1]]`、`[[ref:5,9-11]]`），点击平滑跳转，右下角浮动"↩ 返回刚才位置"多级历史堆栈。
  - 鼠标悬停文献上标或图表链接时，弹出浮层卡片预览题录或图表，无需频繁跳离上下文。
- **非侵入式中英对照**：段落下方的英文来源默认收纳在侧边/折叠区，或通过顶部导航"中英对照"一键全局开启，不破坏默认阅读心流。
- **符号与化学式保护**：`mA cm⁻²`、`Fe⁴⁺`、`¹⁸O`、`[B(OH)₄]⁻` 等严禁误识别为文献跳转，单位与符号紧随公式上下文。
