# 回归测试与质量验证（V4.1）

## 测试资产

- `tests/`：150 项 unittest（结构、路由、术语、校验、性能、装饰墨水、引文与分类回归等，1 项跳过），其中合成样本由 `tests/fixtures.py` 离线生成并明确标注为模拟版式。
- `tests/chemistry`、`double_column`、`single_column`、`table_heavy`、`formula_heavy`、`reference_heavy`、`engineering` 等目录为样本占位（仅 README），真实 PDF 因版权/体积不入仓库。
- `scripts/test_*.py`：旧入口回归（预标记、提取审计、导出、颜色、版式）。

运行方式（在技能目录）：

```powershell
python -X utf8 -m unittest discover -s tests -p "test_*.py" -v
python -X utf8 scripts/test_prepare_reader.py
python -X utf8 scripts/test_extraction_audit.py
python -X utf8 scripts/test_reader_export.py
python -X utf8 scripts/test_pdf_colors.py
python -X utf8 scripts/test_pdf_layout.py
```

- 真实外部样本原位重建回归：Han 9 页、Monat 15 页、Pan 12 页；书目 42/8/75 条编号完整。
